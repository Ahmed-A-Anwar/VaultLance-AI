# F6 — account: profile, password, sessions, delete blockers, sign out

Chromium 1440×900, demo mode, no server row written. Evidence:
`evidence/f6-account.json`, screenshots `shots/f6-*.png`.

| Step | Observation |
|---|---|
| Edit the name | saving shows "Profile saved."; the summary card and the rail chip both read "Amira Hassan" in the same commit |
| Wrong current password | "Current password is wrong." under the field, focus returned to it |
| Right current password | "Password updated."; other sessions leave on a 1.6 s beat, 3 → 1, current session kept |
| Delete account (freelancer) | "Finish or resolve these vaults first." / "Money is still in motion." — 3 blocker rows, each a link; **no email field and no delete control** while blocked |
| Leave the blocked sheet | the first blocker link lands on `/dashboard/vaults` |
| Sign out | lands on the instrument (`/`); `/dashboard` then goes to `/signin`; the stored session is gone |

Friction: **none found**. The blocked-delete sheet replaces the irreversible
control with the reason and the way to each vault, which is the right shape.

Notes:
- Sign out intentionally lands on the marketing page rather than the sign-in
  form; the session guard still catches a direct `/dashboard` visit.
- Password change revokes the other devices after a deliberate delay; the rows
  animate out rather than vanishing, which is why a 0.6 s check sees them and a
  2.4 s check does not.
